# Wiki map

Page titles on the Bogleheads wiki, grouped by what someone is actually trying to do.
URLs follow `https://www.bogleheads.org/wiki/<Title_With_Underscores>`, but search
first — `web_fetch` rejects URLs that haven't appeared in a prior search result.

Titles drift as editors reorganize. If a search for a title comes up empty, search the
concept instead and let the wiki's own search surface the current page.
